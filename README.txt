SIT & FOLD WEBSITE
==================

Files:
- index.html : website structure
- style.js   : responsive styling injected into the page
- app.js     : interactive behaviors
- assets/    : product photo, lifestyle visual, and promo video

How to run:
1. Keep the index.html, app.js, style.js, and assets folder together.
2. Open index.html in a modern browser.
3. For deployment, upload the entire folder to GitHub Pages, Netlify, or another static hosting service.

Notes:
- The product details are based on the supplied Sit & Fold poster/report: adjustable backrest, legrest, foldable table, reclining function, and folding design.
- The contact form opens the visitor's email app using mailto; it does not send data to a server.
